# БЫСТРЫЙ СТАРТ (Docker на сервере)

## 1. Арендовать сервер

**Timeweb** (рекомендую): timeweb.cloud
- Тариф: минимальный (1 CPU, 1 GB RAM)
- OS: Ubuntu 22.04
- Цена: ~250₽/мес

**Получишь:** IP адрес (например `185.123.45.67`)

---

## 2. Подключиться по SSH

```bash
ssh root@185.123.45.67
```

---

## 3. Установить Docker

```bash
curl -fsSL https://get.docker.com | sh
usermod -aG docker $USER
docker --version
```

---

## 4. Загрузить проект

```bash
mkdir -p /opt/english-cards
cd /opt/english-cards
git clone https://github.com/<your-username>/english-cards.git .
```

---

## 5. Создать .env

```bash
cp .env.example .env
nano .env
```

**Обязательно изменить:**
```env
SECRET_KEY=<python3 -c "import secrets; print(secrets.token_hex(32))">
POSTGRES_PASSWORD=<придумать_пароль>
CORS_ORIGINS=https://english-cards.ru
```

---

## 6. Запустить

```bash
docker compose up -d
docker compose ps
docker compose logs -f web
```

---

## 7. Проверить

```bash
curl http://localhost:8000/health
# Ответ: {"status": "ok", "service": "english-cards-api"}
```

# ПОЛНЫЙ ПРОДАКШН (с доменом и HTTPS)

## Шаг 1: Купить домен

**Reg.ru:** reg.ru
- Домен .ru от 199₽/год

**DNS записи:**
```
Тип: A
Имя: @
Значение: 185.123.45.67  (IP сервера)

Тип: A
Имя: www
Значение: 185.123.45.67
```

**Ждать:** 1-24 часа (DNS обновляется)

---

## Шаг 2: Подготовить сервер

```bash
# Обновить систему
apt update && apt upgrade -y

# Установить Docker
curl -fsSL https://get.docker.com | sh
usermod -aG docker $USER

# Установить Nginx
apt install nginx -y

# Установить Certbot
apt install certbot -y
```

---

## Шаг 3: Получить SSL

```bash
# Остановить Nginx (чтобы освободить порт 80)
systemctl stop nginx

# Получить сертификат
certbot certonly --standalone -d english-cards.ru -d www.english-cards.ru

# Автообновление
(crontab -l 2>/dev/null; echo "0 3 * * * certbot renew --post-hook 'systemctl reload nginx'") | crontab -
```

---

## Шаг 4: Настроить Nginx

```bash
nano /etc/nginx/sites-available/english-cards
```

**Вставить (заменить домен!):**
```nginx
server {
    listen 80;
    server_name english-cards.ru www.english-cards.ru;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name english-cards.ru www.english-cards.ru;

    ssl_certificate /etc/letsencrypt/live/english-cards.ru/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/english-cards.ru/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /health {
        proxy_pass http://127.0.0.1:8000;
        access_log off;
    }

    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}
```

**Активировать:**
```bash
ln -s /etc/nginx/sites-available/english-cards /etc/nginx/sites-enabled/
rm /etc/nginx/sites-enabled/default
nginx -t
systemctl start nginx
systemctl enable nginx
```

**Запустить:**

# ПРОБЛЕМЫ И РЕШЕНИЯ

## Контейнер не запускается

```bash
# Посмотреть логи
docker compose logs web

# Перезапустить
docker compose restart web

# Пересобрать
docker compose up -d --build
```

## Ошибка подключения к БД

```bash
# Проверить что БД запущена
docker compose ps db

# Логи БД
docker compose logs db

# Проверить .env
cat .env | grep POSTGRES
```

## Миграции не применяются

```bash
# Проверить версию
docker compose exec web python db.py current

# Применить
docker compose exec web python db.py upgrade

# Откатить и применить
docker compose exec web python db.py downgrade -1
docker compose exec web python db.py upgrade
```

## Nginx не работает

```bash
# Проверить конфиг
nginx -t

# Перезапустить
systemctl restart nginx

# Статус
systemctl status nginx

# Логи
tail -f /var/log/nginx/error.log
```

## 502 Bad Gateway

```bash
# Проверить что backend запущен
docker compose ps web

# Проверить порт
curl http://127.0.0.1:8000/health

# Если не работает - перезапустить
docker compose restart web
```

## SSL истёк

```bash
# Обновить
certbot renew

# Проверить
certbot certificates
```

# БЕЗОПАСНОСТЬ

## Что настроить обязательно

```bash
# 1. Файрвол
ufw allow 22/tcp   # SSH
ufw allow 80/tcp   # HTTP
ufw allow 443/tcp  # HTTPS
ufw enable

# 2. Отключить вход по паролю SSH (использовать ключи)
nano /etc/ssh/sshd_config
# PasswordAuthentication no
systemctl restart sshd

# 3. Обновления безопасности
apt install unattended-upgrades -y
dpkg-reconfigure -plow unattended-upgrades
```

## .env файл

```bash
# НИКОГДА не коммить в Git!
# Проверить .gitignore:
cat .gitignore | grep .env

# Права на .env
chmod 600 /opt/english-cards/.env
```
