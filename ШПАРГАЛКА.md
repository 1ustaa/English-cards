# БЫСТРЫЙ СТАРТ (запуск по HTTP без SSL)

**Используй пока домен не верифицирован!**

## 1. Арендовать сервер

**Timeweb** (рекомендую): timeweb.cloud
- Тариф: минимальный (1 CPU, 1 GB RAM)
- OS: Ubuntu 22.04
- Цена: ~250₽/мес

**Получишь:** IP адрес (например `185.123.45.67`)

---

## 2. Подключиться по SSH

```bash
ssh root@185.123.45.67
```

---

## 3. Установить Docker

```bash
curl -fsSL https://get.docker.com | sh
usermod -aG docker $USER
docker --version
```

---

## 4. Загрузить проект

```bash
mkdir -p /opt/english-cards
cd /opt/english-cards
git clone https://github.com/1ustaa/English-cards.git .
cd English-cards
```

---

## 5. Создать .env

```bash
cp .env.example .env
nano .env
```

**.env:**
```env
FLASK_APP=wsgi.py
FLASK_ENV=production

# Сгенерировать: python3 -c "import secrets; print(secrets.token_hex(32))"
SECRET_KEY=<случайная_строка>

POSTGRES_USER=english_user
POSTGRES_PASSWORD=<надежный_пароль>

# Временно HTTP (позже сменим на HTTPS)
CORS_ORIGINS=*

# Для сброса пароля (потом настроим)
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
FRONTEND_URL=http://185.123.45.67
```

---

## 6. Запустить

```bash
docker compose up -d
docker compose ps
docker compose logs -f web
```

---

## 7. Проверить

```bash
curl http://localhost:8000/health
# Ответ: {"status": "ok", "service": "english-cards-api"}
```

# НАСТРОЙКА NGINX (доступ по порту 80)

**Чтобы не писать :8000, настроим Nginx:**

```bash
# Установить Nginx
apt install nginx -y

# Создать конфиг
nano /etc/nginx/sites-available/english-cards
```

**Вставить (заменить IP!):**
```nginx
server {
    listen 80;
    server_name 185.123.45.67;  # <-- ТВОЙ IP ИЛИ ДОМЕН

    # Frontend + API
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Gzip сжатие
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}
```

**Активировать:**
```bash
ln -s /etc/nginx/sites-available/english-cards /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl restart nginx
systemctl enable nginx
```

**Открыть порт в файрволе:**
```bash
ufw allow 80/tcp
ufw allow 8000/tcp
ufw status
```

# ДОБАВИТЬ HTTPS ПОЗЖЕ (когда домен верифицирован)

## Шаг 1: Получить SSL

```bash
apt install certbot -y

# Остановить Nginx временно
systemctl stop nginx

# Получить сертификат
certbot certonly --standalone -d qardly.ru -d www.qardly.ru

# Запустить Nginx обратно
systemctl start nginx
```

## Шаг 2: Обновить Nginx

```bash
nano /etc/nginx/sites-available/english-cards
```

**Заменить на:**
```nginx
server {
    listen 80;
    server_name qardly.ru www.qardly.ru;
    return 301 https://$host$request_uri;  # Redirect HTTP -> HTTPS
}

server {
    listen 443 ssl;
    server_name qardly.ru www.qardly.ru;

    ssl_certificate /etc/letsencrypt/live/qardly.ru/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/qardly.ru/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}
```

**Перезапустить:**
```bash
nginx -t
systemctl restart nginx
```

**Проверить:**
```
https://qardly.ru
```

## Шаг 3: Автообновление SSL

```bash
(crontab -l 2>/dev/null; echo "0 3 * * * certbot renew --post-hook 'systemctl reload nginx'") | crontab -
```

# ПРОБЛЕМЫ И РЕШЕНИЯ

## Контейнер не запускается

```bash
docker compose logs web
docker compose restart web
docker compose up -d --build
```

## Ошибка подключения к БД

```bash
docker compose ps db
docker compose logs db
cat .env | grep POSTGRES
```

## Миграции не применяются

```bash
docker compose exec web flask db current
docker compose exec web flask db upgrade
docker compose exec web flask db downgrade -1
docker compose exec web flask db upgrade
```

## Nginx не работает

```bash
nginx -t
systemctl restart nginx
systemctl status nginx
tail -f /var/log/nginx/error.log
```

## 502 Bad Gateway

```bash
# Backend не запущен
docker compose ps web
curl http://127.0.0.1:8000/health
docker compose restart web
```

## Приложение не открывается снаружи

```bash
# Проверить файрвол
ufw status

# Открыть порты
ufw allow 22/tcp   # SSH
ufw allow 80/tcp   # HTTP
ufw allow 8000/tcp # Backend
ufw status
```
